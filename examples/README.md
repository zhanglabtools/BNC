# Examples

Examples are small API demonstrations, not formal experiments.

## Metric walkthrough

```bash
python examples/metric_walkthrough.py
```

The script demonstrates best cyclic score, token-geometry correlation, a fixed
shuffled negative control, participation rank, and spectral summaries on
synthetic geometry with known structure.

Use the configured CLI for training grids. Do not copy an example's synthetic
values into `paper_data/` or cite them as empirical reproduction evidence.
